# Sources And Audit

## Current Sources

中国侧：

- 参考消息：中国、国际、科技应用、产经、观点；
- 新华网：时政、科技；
- 环球网：国际、科技。

挪威侧：

- NRK 最新新闻 RSS；
- VG 最新新闻 RSS。

## Why People.cn Was Removed

人民网 RSS 可以抓到 80 条内容，但返回的日期长期不是当天，例如旧的 `2025-06-05`、`2024-07-03`、`2021-10-14`。这不是日期解析失败，而是 RSS 源本身不适合做当天新闻监控。

因此项目改用参考消息 JSON 列表补充中国侧信息源。参考消息的列表接口能提供标题、发布时间和跳转链接，适合做国际时政和中文读者视角的线索入口。

## Audit Design

日报不是假装“绝对完整”，而是把来源风险暴露出来：

- `total_fetched`：这个来源抓到了多少条；
- `today_count`：其中多少条能证明是目标日期；
- `selected_count`：最终入选多少条；
- `notes`：来源失败、日期不匹配、HTML 日期不完整等风险提示。

这种设计适合真实项目，因为新闻源经常变化。与其静默失败，不如把失败显示在网页和 `data/audit.json` 里。

## Known Limitation

参考消息页面是前端渲染，列表能稳定抓标题和日期，但正文提取通常不完整。因此参考消息条目的摘要更多依赖标题、栏目和关键词线索。关键判断仍建议点击原文和多源核查。
